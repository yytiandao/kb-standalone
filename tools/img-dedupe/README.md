# 图片查重工具（只读）

找出 `images/ref/`（素材库）与 `images/`（条目配图）中**内容重复**的图片，产出报告与人工对照页。不移动、不删除、不改任何数据。

## 用法

```bash
node  dump-kbimg.js   # 导出 data/img.js + data/items.js 元数据 → kbimg.json（中间产物，已 gitignore）
python dedupe.py      # 生成 report.md / groups.html / index.json（约 100 秒）
```

依赖：Python 3.10+ 与 Pillow。

## 判定口径

每图先 EXIF 转正 + 裁均匀留白；dHash(64bit) 距离 ≤20 预筛候选对，再按【分块局部匹配分 m】定夺（4×4 块、每块在 ±1 块邻域内找最佳余弦、跳过纯背景块、**双向取平均**——单向高分+反向低分意味着"部分包含"，会落到 C 区）：

- **A 类**：组内所有文件 MD5 相同（字节级重复）
- **B 类**：m ≥ 0.65 —— 同一图片的不同版本（转码 / 缩放 / 水印 / 裁剪变体）
- **C 类**：m ∈ [0.50, 0.65) 的【对】—— 疑似，按对报告不做传递合并（同一 PPT/文章的系列模板图多落此区），人工判断

## 为什么不用 pHash / 全图 NCC

本语料是白底线稿类技术图，实测：

| 信号 | 结果 |
|---|---|
| pHash(DCT) | 白底主导低频，数百张不同图连成一个巨型组，弃用 |
| 全图灰度 NCC | 区间重叠：同图缩放变体 0.79 < 同模板不同页 0.90，无法切分 |
| **分块局部匹配** | 同图变体 0.70+ ／ 同模板不同页 ≤0.59 ／ 完全不同 ≤0.35，分离清晰 |

## 产出

- `report.md`：分组清单（来源文章、dHash 距离、匹配分、建议保留者=分辨率最高那张）
- `groups.html`：人工对照页，每组缩略图并排、可勾选 A/B/C 层级过滤，点击看原图
- `index.json`：机器可读结果（分组、候选对、孤儿文件、缺失引用），供后续清理脚本使用

确认对照页后的清理动作（隔离文件、更新 `data/img.js`、同步 `ref/thumb`、重跑 `content-check.js`）需另行执行，本工具不做。
